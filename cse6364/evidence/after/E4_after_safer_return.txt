Code-level proof — the actual changes
======================================================================
librarian/session.php
  + initialises $_SESSION['csrf_token'] (64-hex from random_bytes(32))
  + defines csrf_field() helper to render the hidden <input>
  + defines csrf_check() using hash_equals() (constant-time compare)

librarian/return_save.php
  Before (10 lines): include dbcon, read $_GET, raw UPDATE with
                     string-interpolated SQL, redirect.
  After  (45 lines): include session (auth), require POST, require
                     CSRF, cast IDs to int, prepared SELECT to verify
                     pending status, prepared UPDATE with affected-rows
                     check, flash success/error.

librarian/modal_return.php
  Replaces the `<a href="return_save.php?id=...&book_id=...">Yes</a>`
  with a `<form method="POST" action="return_save.php">` that carries
  id, book_id, AND the CSRF token from csrf_field().

librarian/view_borrow.php
  Adds a flash display block above the table that renders
  $_SESSION['flash_success'] (green) and $_SESSION['flash_error']
  (red), and unsets each after display so it's one-shot.
